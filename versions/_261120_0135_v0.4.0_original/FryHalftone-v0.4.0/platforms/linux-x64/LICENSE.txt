二、第三方组件
--------------------------------------------------------------------
★ 本库**不链接任何第三方开源库**。以下功能都是自研实现（按公开规范写的，便于与 Python
  生产线做逐位一致的对账）：

  · PNG 解码            —— 自研（RFC 2083 / PNG 规范）
  · DEFLATE(inflate)    —— 自研（RFC 1950 / 1951）
  · 基线 JPEG 解码      —— 自研（ITU-T T.81 基线，1 / 3 分量）
  · MD5                 —— 自研（RFC 1321，仅用于产物自校验，不用于安全用途）
  · glTF / GLB 解析     —— 自研（glTF 2.0 规范 + KHR_texture_transform、KHR_mesh_quantization）
  · JSON 解析           —— 自研
  · 线程池 / 数学函数    —— C++ 标准库（std::thread 等）与平台 C 运行库

运行期依赖：
  · Windows —— 仅依赖系统自带的 ucrtbase.dll 等 Windows 组件；C++ 运行库已静态链接，
               **不需要安装 VC++ Redistributable**。
  · Linux   —— libstdc++ / libgcc 静态链接；依赖 glibc 与 libpthread。
  · macOS   —— 系统自带运行库。
