## 两项上线边界

128 喷孔示例：16.851 mm 的半球按该测试姿态生成 131 列，指定 128 会拒绝裁切。改为 16.0 mm 后产生 125 列原生数据，可补 3 空列至 128 列、809 层。设备宽度和模型尺寸需要分别记录。

HE510 斜角示例：同一 6 mm 半球设 axis_map、+short 朝上、+mid 朝前、yaw=45°，Windows 与 Linux x64 在 309 层中有 24 层、29 个材料体素不同。法线柱的离散取整对三角函数计算末位敏感。需要跨任务哈希严格复现时，固定平台或使用按平台建立的基准。
